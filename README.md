# cloud-admin-lab

Hands-on learning portfolio focused on Windows Server and Active Directory, Microsoft Entra ID, Microsoft 365, Azure, and PowerShell.

Lab scenarios use the fictional company **SmallCo**.

## Repository guide

| Folder | Purpose |
| --- | --- |
| [docs](docs/) | Environment documentation, technical notes, and learning records. |
| [labs](labs/) | Lab scenarios, procedures, results, and verification evidence. |
| [scripts](scripts/) | PowerShell scripts and other automation tools. |
| [runbooks](runbooks/) | Repeatable operational and troubleshooting procedures. |
| [postmortems](postmortems/) | Incident analysis, root causes, fixes, and prevention. |
| [iac](iac/) | Infrastructure as code, including Bicep templates. |

## Status

Initial repository setup. Lab content will be added as exercises are completed.
